# Resource Booking System

## MySQL
CREATE DATABASE resource_booking_db;

Then edit:
src/main/resources/application.properties

Replace YOUR_MYSQL_PASSWORD with your real MySQL password.

## STS
File > Import > Maven > Existing Maven Projects > select project folder.
Set Java 17.
Maven > Update Project.
Run ResourceBookingApplication as Spring Boot App.

No Lombok is included in this project.
